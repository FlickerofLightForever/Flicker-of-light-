# Flicker of Light — Website

This is the first website version for the Flicker of Light writing project.

## Files
- `index.html` — homepage
- `chapter-one.html` — first story chapter
- `style.css` — visual design

## Publish with GitHub Pages
1. Create/sign into a GitHub account.
2. Create a new PUBLIC repository, e.g. `flicker-of-light`.
3. Upload these files to the repository root.
4. Open Settings → Pages.
5. Under Build and deployment, choose "Deploy from a branch".
6. Select the `main` branch and `/ (root)`, then Save.
7. GitHub will provide the public website URL.

## Before publishing
Replace the placeholder Chapter One text with the final chapter.
You can also change the Instagram link in `index.html` to your real profile URL.

The design is mobile-first and intended to be linked from Instagram.
